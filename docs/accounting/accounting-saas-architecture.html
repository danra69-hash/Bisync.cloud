Accounting SaaS architecture

Upstream multi-tenant ledger blueprint adapted to the current Bisync build: company = tenant, ASP.NET Core + PostgreSQL, optional dedicated company DBs, payroll and RMS inventory as live bridges into Books Phase 0.

Wiring

Payroll

PayrollRunsController.Process → AccountingBridgeService.OnPayrollProcessedAsync

Dr 5100 salaries + Dr 5110 employer statutory · Cr 2100/2110/2120/2130 payables. Idempotent key hrm.payroll_posted:{company}:{year}:{month}.

Inventory / purchase

PurchaseOrdersController.Reconcile (consolidate) → OnPurchaseAffirmedAsync

Dr 1400 Inventory · Cr 2000 AP for affirmed component lines (excludes returnable deposits). Stock card / FIFO remain the quantity/cost layers.

Failure policy

Bridge errors are logged and outboxed; they must not fail payroll or consolidate — ops remains source of truth.

Phase roadmap

  1. Phase A / B (this build) — Hub honesty + Phase 0 post/reverse/TB/outbox + payroll & consolidate bridges.
  2. Phase C — Versioned SLA rule sets, richer COA, AP/AR open items.
  3. Phase D — Localisation packs, e-invoicing aggregator, statutory exports.
